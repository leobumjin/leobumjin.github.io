{% if include.lang == 'kr' %}Hidden은 독수리 / 펭귄 / 날다 / 헤엄치다의 4차원이다. 각 출력은 직접 정한 대각행렬 K를 이용한 선형 함수 F(h) = Kh다. J-lens는 같은 층에서 선택한 출력들의 평균 K를, Logit Lens는 identity를 사용한다. 두 경로 모두 softmax(3 · L2-normalize(·))로 읽는다. 한 문맥의 Gₛ를 이용한 읽기 예시이며 sparse J-space 복원을 수행하지 않는다. 실제 층이 종과 행동을 나눌 필요는 없다.{% else %}Hidden vectors have four coordinates: Eagle / Penguin / Fly / Swim. Each output map is linear in the selected input: F(h) = Kh, with a hand-set diagonal K. J-lens uses the mean K for selected output positions at one layer; Logit Lens uses the 4 × 4 identity. Both decode with softmax(3 · L2-normalize(·)). This single-context Gₛ illustrates a readout step, not sparse J-space reconstruction. Real layers need not separate species and actions.{% endif %}
